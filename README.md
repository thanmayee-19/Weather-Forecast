# Weather App

A simple and responsive **Weather Application** that provides real-time weather information based on a user's location search.

## Features

* Search weather by city/location
* Display current weather information
* Dynamic data updates
* Responsive and user-friendly interface
* Error handling for invalid locations/API failures

## 🛠️ Tech Stack

* **HTML5** – Application structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Frontend logic, API requests and DOM manipulation
* **Node.js** – Backend runtime
* **Express.js** – Server and API request handling
* **Weather API** – Provides real-time weather data

```

##  How It Works

1. User enters a city name.
2. `script.js` sends a request to the Node.js backend.
3. The backend communicates with the Weather API.
4. Weather data is returned to the frontend.
5. JavaScript dynamically displays the weather information.

## Setup

```bash
git clone <your-repository-url>
cd Weather
cd server
npm install
node server.js
```

Then open the application using the local server URL, for example:

```text
http://localhost:3000
```
