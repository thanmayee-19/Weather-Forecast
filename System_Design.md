Memory and Storage Systems

Computer Memory

Computer memory is divided into two primary types: RAM and ROM.

RAM (Random Access Memory)
RAM is a temporary storage area that holds data while programs are running. It is volatile memory, meaning all data is lost when the power is turned off. It allows the system to manage multiple applications simultaneously by providing fast access to active data.

ROM (Read Only Memory)
ROM is a permanent storage area that is non-volatile, meaning it retains its data even when power is disconnected. It stores essential instructions such as the BIOS (Basic Input/Output System), which is the first application to run when a computer powers up to control how hardware devices communicate.

Types of RAM

Static RAM (SRAM)
SRAM is fast and expensive. It is used in high-speed applications like CPU caches where quick data access is critical. Unlike other types, it does not require constant refreshing.

Dynamic RAM (DRAM)
DRAM is slower and cheaper than SRAM. It is considered high maintenance because it requires constant refreshing of its electrical charge to maintain data. Two common subtypes of DRAM include:
1. SDRAM (Synchronous Dynamic RAM)
2. GDDR (Graphics Double Data Rate RAM)

Storage Systems

Hard Disk Drive (HDD)
HDDs store data on large magnetic disks. They are known for offering very large storage capacities at a low price, though they are slower than modern alternatives due to their mechanical parts.

Solid State Drive (SSD)
SSDs store data using NAND-based flash technology. They provide much faster data access speeds and reduced power consumption compared to HDDs because they have no moving parts.

Portable Storage

Flash Drives (USB Devices)
These are portable storage devices used with USB ports. They are designed for easily copying and sharing files from one system to another.

SD Cards
Commonly used in cameras and phones, SD cards can store thousands of files in a very small form factor. They typically come in three physical sizes:
1. SD
2. MicroSD
3. MiniSD
